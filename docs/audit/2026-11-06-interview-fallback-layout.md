# 面试截图备用通道与浮窗布局

日期：2026-11-06。发布状态以版本标签和发布流水线为准，保留之前的容错加固；README 对比资料链接不纳入提交。

## 最终交互

- 移除“补充我的实际回答”按钮和表单，保留历史记录及自动识别的候选人回答。
- 顶部仅显示一行设备与收音状态，异常时保留提示。
- 移除浮窗的顶部、底部音量条以及按钮、拖动、结束操作的悬停进度条。悬停触发和确认逻辑保留，用低调边框反馈悬停状态。
- 面试中点击“截图提问”或截图快捷键，直接进入面试内嵌的截图答题区，复用笔试的截屏、视觉作答、流式输出、截图附件保存与追问流程。无需单独 OCR、修改题目或确认发送。
- 截图答题记录关联当前面试会话，答案展示后可“返回对话”；原有笔试入口仍可进入该区域。此前添加的独立 OCR 模块和测试已移除。
- 收音异常不阻止使用截图答题。手动问答完成后也保留原暂停/错误状态，不把回答成功误当作收音恢复。

## 按钮布局

原按钮一行等分宽度，快捷键占据不可缩小空间，主标签采用截断，窄窗口下容易被压得看不见。

共享文字按钮改为最小宽度 80px、字体 12.5px，操作行空间不足时换行；快捷键放在文字下方，标签可折行。图标按钮不挤缩。面试、内嵌笔试、独立笔试均应用，底栏过高时可滚动。
