# 面试与笔试辅助：异常恢复加固

目标：提高使用中的连续性、恢复能力和内容保留能力，而不是隐藏报错或无限延长等待。日期：2026-11-06。

## 本轮处理的高影响路径

| 场景 | 处理 |
| --- | --- |
| 实时语音小包发送跟不上采集 | 合并待发小包为最多 100ms 的 PCM 帧；验证音频完整有序，不以丢数据或扩大队列掩盖拥塞 |
| 断线重连时旧发送未结束 | 按连接代次隔离发送泵，新连接可继续，不受旧请求完成/失败影响 |
| 真正的语音发送堵塞 | 排队与发送中音频合计仍限制在两秒；停止并明确提示，避免旧问题滞后数十秒才被识别 |
| 面试/笔试模型临时返回 408、429、500/502/503/504 | 仅在没有输出任何内容时延迟补试一次，复用原请求内容和会话，不新增问题或转用其他服务 |
| 用户取消或结束时正在等待补试 | 立即取消等待，不发送替代请求；原有会话代次检查继续阻止迟到结果污染新会话 |
| 长时间等待 | 首次请求、补试延迟和第二次请求共用配置的总超时预算，而非每次重新计时 |
| 认证失败、格式错误、已有部分输出后中断 | 不自动重试，避免反复扣费或产生两份答案；已有部分内容保留，并显示失败 |
| 笔试记录首次落盘失败 | 阻止上传模型，保留收集的截图以便恢复后重新发送，无需重新截题；截图附件单独保存失败时仍沿用已有的明确告警策略 |
| 笔试解题或追问失败，错误处理中保存也失败 | 第二次保存错误在引擎内收口，状态进入可恢复错误，快捷键/悬停入口不再收到未捕获的 Promise 拒绝；已有答案保留 |
| 模型已完成，仅最终保存失败 | 不把已完成答案标成生成失败；保留正文和完成标记，提示未保存 |

## 既有保护与本轮复核范围

已有会话代次隔离、结束/暂停取消、笔试流式检查点、未保存答案保留、历史恢复、输入互斥及错误恢复界面。本轮在这些保护上检查新缺口；没有重新实现整个状态机，也没有对所有设备和外部服务宣称全覆盖。

实时发送的复现、字节级对照和边界说明见 [实时 ASR 积压复核](2026-11-06-realtime-asr-backlog.md)。

新增回归直接覆盖：

- 两页截图遇到磁盘失败，入口正常结束、未请求模型；恢复后重试使用原来的两页，不额外截屏。
- 追问已有部分输出，同时模型请求与保存失败，正文保留、计时停止、入口正常结束。
- 临时服务故障只补试一次，成功后只有一份回答与一条请求追踪记录。
- 持续故障最多两次请求，401 仅一次请求。
- 补试等待中取消，不发第二次请求。
- 已输出内容后出现类似 503 的流错误，不重试、不重复追加部分答案。

使用合成记录与模拟响应验证，不录制或上传真实用户资料，不消耗真实模型额度。日志位于本机忽略目录 `artifacts/audit/assistance-resilience-*`。

验收结果：343 项自动测试通过、13 项现有浏览器边界检查通过；TypeScript 检查及生产前端构建通过。尚未进行本轮 macOS 实机故障注入测试。

## 仍然明确保留的边界

- 真实断网、设备被拔出、权限被撤销或服务持续不可用，不保证不中断；应停止相关任务、显示恢复入口并保留其余工作内容。
- 磁盘不可写时只能保留运行中内存里的最新内容，不能保证此时强制结束进程仍可恢复；持久化成功的检查点才具备重启后的恢复保障。
- 服务商可能对失败请求计费；自动补试仅限明确的临时 HTTP 状态、无输出且一次，不扩展为任意异常无限重试。
- 本轮未增加自动切换模型服务或识别模式，避免静默改变数据接收方和识别行为；未增加未经确认的系统权限请求。
- 原生崩溃、系统强杀、硬件故障与 macOS 实机全屏/音频行为仍需针对环境验证；前端测试通过不能替代实机验收。
