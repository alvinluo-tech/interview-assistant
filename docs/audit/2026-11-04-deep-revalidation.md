## 3. 已确认但尚未修复的问题

### R04 · P1 · 结束面试后，迟到的启动流程仍重新打开收音（本轮新增）

位置：`src/overlay/InterviewOverlay.tsx:77` 的启动 effect，尤其第 110–111 行；`src/lib/interviewEngine.ts:809` 的 beginListening。

实际调用链：

1. 启动流程创建面试会话，检查会话仍有效。
2. 等待 `setSetting('interview.sessionId', session.id)` 完成。
3. 等待期间结束面试：引擎切为 ended，释放采集，清空 sessionId。
4. 配置保存返回，旧启动流程直接调用 beginListening，没有再次确认会话归属或是否已结束。
5. beginListening 会建立新的采集代次，没有拒绝空会话，因此再次打开麦克风并进入 listening。

**D04 复现使用真实 InterviewOverlay 与真实 interviewEngine，只替换配置存储、设备、平台和 AI 依赖。** 暂停配置写入 → 调用真实 endInterview(false) → 放行写入。结果：

```json
{"status":"listening","sessionId":null,"micStarts":1,"micCloses":0}
```

micStarts 是合成采集驱动被真实引擎调用的次数，不是真实设备录音。复现后再次结束引擎，确认合成采集被清理。没有向外发送录音或调用真实转写服务。

影响：用户已结束面试，但旧启动任务可重新收音，并进入没有会话归属的运行状态。真实语音输入后是否上传未在本轮执行；不能把它描述为已经发生真实音频外传。

修复方向：启动任务需要跨越所有 await 的会话归属检查及卸载取消；beginListening 也应拒绝无有效会话的迟到调用，形成第二道保护。恢复已有会话的启动分支同样要核验，不能只修其中一个调用点。

建议验收：在创建会话、保存 sessionId、打开设备、恢复已有会话各等待点分别结束/隐藏/切换会话，保证旧任务无法开启采集，也不能污染新会话。此项应优先于发版处理。

### R03 · P2 · 旧显示快照覆盖了较新的隐藏事件（本轮新增）

位置：`src/overlay/OverlayApp.tsx:44` 的显示/隐藏 effect，第 59 行的 overlayShowSeq 返回处理。

- 启动时订阅 overlay-shown/overlay-hidden，同时异步查询初始显示快照。
- 隐藏事件把 active 设为 false。
- 较早发起的查询若随后返回正 showSeq，仍无条件把 active 设为 true，没有校验快照是否已经被事件取代。
- 原生 `cmd_overlay_show_seq` 只返回读取时的可见序号；前端不能将迟到的结果视为比已收到的隐藏事件更新。

D03 执行真实根组件 effect，用受控 IPC 时序依次发出 shown(7)、hidden，再返回旧快照 7：active 从 false 重新变成 true。

影响边界：确认的是**前端隐藏状态被重新激活**，可能重新挂载业务组件、执行启动副作用。本轮没有证明操作系统窗口自行显示，也没有在此探针打开真实设备，不把这些推论当成已观测结果。

修复方向：初始快照与后续事件共用版本/归属保护；事件发生或 effect 清理后，忽略旧快照。验收需同时覆盖旧正值覆盖隐藏、旧 0 覆盖新显示、卸载后返回及重复事件。

### R01 · P2 · 普通业务弹窗缺少完整模态焦点约束（上轮发现，本轮重现）

位置：`src/ui/primitives.tsx:156` 的 Dialog；“新建岗位”等实际业务入口使用。

打开新建岗位表单，从输入框按 Tab，焦点会到弹窗外 BODY，而表单仍打开。普通 Dialog 没有复用语音弹窗的焦点循环、背景 inert 与完整 dialog 语义。语音弹窗 F03 的修复不能代表所有弹窗。

修复时应统一管理最上层弹窗，覆盖嵌套层级、Escape、焦点恢复；不能让每层各自的全局监听器互相争抢。

### R02 · P3/潜在 · 未使用的 useClickOutside 存在延迟订阅泄漏（上轮发现，本轮重现）

位置：`src/ui/primitives.tsx:374`。

effect 安排定时器添加 mousedown 监听，清理时只移除监听、没有取消定时器。卸载发生在定时器执行前时，后续又添加了监听，最终残留 1 个。

当前 src 只有定义，没有调用点。因此确认的是辅助函数的潜在缺陷，**没有证据证明当前页面因此持续泄漏、变卡或堆积录音**。可以删除未使用函数，或补齐定时器取消和快速挂载/卸载回归。
