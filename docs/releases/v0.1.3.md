# Mianxu v0.1.3

This release improves phone display control, exam review and mock interviews, and introduces a consistent branded Windows installation and update experience.

## Highlights

- Replace the traditional Windows installation entry, progress and completion pages with a branded native interface, installation-folder selection and an explicit launch action.
- Keep phone pairing when returning to the computer, resume the phone display without scanning again, support desktop hover actions and show the complete question history.
- Save recognized exam questions separately from answers and compressed screenshots. Review source images with paging and zoom while retaining their original dimensions.
- Redesign mock interviews around a two-person layout, a collapsible transcript and a speaker toggle. Use configured speech services or the operating system's voice when no TTS service is configured.
- Separate mock interview history and organize records, attachments, backups, cache and logs. Add a storage settings page and clearer AI service and developer information.

## Reliability

- Download and verify official Windows installers inside the app for development and portable builds, instead of redirecting the primary action to GitHub. Managed installations retain signed in-app updates with explicit installation consent.
- Prevent record refreshes from leaving mock opening questions stuck, and discard cancelled or late question and speech responses.
- Preserve existing data during storage migration and retain the original legacy files. Keep transparent screenshots intact and clean up only incomplete attachment batches.
- Preserve the upstream installer behavior for existing-install detection, reinstall and uninstall choices, downgrade handling and WebView2 setup.

## Upgrade notes

Existing settings and credentials keep their protected storage location. Record migration runs when the new application first reads its records. To move records to another computer, copy both the record and attachment folders; JSON record backups do not contain screenshot files.

Windows x64 and macOS Apple Silicon/Intel packages are included. Physical-device acceptance of macOS capture/audio and phone scaling/reconnection remains pending; successful compilation is not a substitute for those device checks.
