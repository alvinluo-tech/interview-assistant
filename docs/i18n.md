# i18n 架构（多语言实现）

## 支持的语言

界面语言与语言选择器（设置 → 通用）一致，共 9 个 locale：

| locale | 语言 | 实现方式 |
| --- | --- | --- |
| `zh-cn` | 简体中文 | 源语言：key 即文案，无需词典 |
| `en` | English | 词典 `src/lib/i18n/locales/en.ts` |
| `pt-br` | Português (Brasil) | 词典 `pt-br.ts` |
| `es-419` | Español (Latinoamérica) | 词典 `es-419.ts` |
| `vi` | Tiếng Việt | 词典 `vi.ts` |
| `tr` | Türkçe | 词典 `tr.ts` |
| `ko` | 한국어 | 词典 `ko.ts` |
| `ja` | 日本語 | 词典 `ja.ts` |
| `zh-tw` | 繁體中文 | 简繁转换器实时生成（词组优先、单字兜底） |

## 核心设计

- **key = 简体中文源文案**：`t('设置')` 的 key 与界面原文逐字一致（含标点）。zh-cn 下 `t()` 原样返回 key，因此对默认行为与既有测试零影响。
- **切换即刷新**：`switchLocale()` 持久化 `desktop.locale` 并广播 `desktop-locale-changed`，主窗口/模拟面试窗整窗 reload，浮窗在会话空闲后刷新。因此 `t()` 无需订阅/响应式，渲染路径零开销。
- **占位符**：`t('已选 {count} 份', { count })`，替换用 `{name}` 语法，翻译时必须原样保留占位符。
- **回退链**：目标语言词典 → en 词典 → key 原文。词典完整性由测试强制（见下），正常运行不会触发回退。

## 模块结构

```
src/lib/i18n.ts              核心：locale 解析、t()/translate()、切换广播、zh-tw 转换器
src/lib/i18n/locales/en.ts   英语词典（key 对齐的基准）
src/lib/i18n/locales/…ts     其余语言词典（与 en 逐 key 对齐）
```

## 翻译范围与豁免

**必须翻译**（经过 `t()`）：

- 所有窗口的界面 chrome：导航、按钮、表单标签、占位符、aria-label、对话框、toast。
- lib 层抛出的、会显示给用户的错误/状态文案（静态文案在 throw 点包 `t()`；插值文案用占位符）。
- 更新日志、使用须知、引导流程等静态内容。

**明确豁免**（不经过 `t()`，属于数据/协议）：

- **AI 提示词**：system/user prompt、工具 description、TTS 朗读指令——发送给模型的内容，不渲染到界面。
- **专有名词数据**：TTS 音色名（厂商定义）、品牌名 `BRAND`。
- **逻辑/持久化**：正则匹配、状态枚举比较（`=== '聆听中'`）、写盘的键值与枚举——这些只在显示点包 `t()`。
- **用户/动态内容**：简历、岗位、题库、AI 生成的回答与复盘报告。
- **原生层诊断信息**：Rust 侧（src-tauri）错误字符串是诊断详情，通常作为次级 detail 展示；主文案在 JS 边界翻译。

## 语言统一性验证（tests/i18n.test.mjs）

1. **key 对齐**：7 个目标词典与 en 逐 key 对齐，缺失/多余即失败——杜绝"切到某语言后某句回退英文"。
2. **无 CJK 残留**：en/pt-br/es-419/vi/tr/ko/ja 的任何译文包含 CJK 字符即失败。
3. **占位符保留**：译文丢失/新增 `{name}` 占位符即失败。
4. **端到端翻译**：注入 locale 后 `t()` 不得返回中文原文。
5. **zh-tw 完整性**：所有 key 经转换器后不得遗留简体特有字（未映射字符须审校后冻结在测试白名单中）。
6. **源码扫描**：扫描 `src/` 中未经 `t()` 的用户可见 CJK 文案；提示词/词典/转换表在测试 POLICY 白名单中整文件或逐行豁免（豁免必须写理由）。

## 新增文案的流程

1. 在组件中写 `{t('新文案')}`（key = 中文原文）。
2. 在 `src/lib/i18n/locales/` 全部 7 个词典补齐该 key（`tests/i18n.test.mjs` 会校验）。
3. zh-tw 若含未映射简体字，扩充 `i18n.ts` 的 `ZH_TW_PHRASES` / `ZH_TW_CHARS`。
