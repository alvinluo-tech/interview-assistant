# 官方对照复核与设计采纳记录

日期：2026-10-30。状态：静态证据复核完成；未验证原版服务端行为或模型质量。

## 1. 如何使用这份参考

用户提供的文本与仓库中的 [官方 AI 对照分析](../../audit/ai-vs-official-comparison.md) 在去除 BOM、统一换行并去除首尾空白后内容一致。原报告原样保留，本文记录进一步的判断。

原分析最有价值的是整理了客户端可观察的契约。其个别“架构性消除”“协议已解”“有评测闭环”等结论，比当前证据能支持的范围更强。我们借鉴机制，不继承这些质量结论。

证据分类：

- **S：静态可确认**。本轮在本机 h13 文件中直接找到字段、事件或调用。
- **R：参考报告陈述**。原报告或规格描述，未在本轮逐项重做验证。
- **U：服务端未知**。客户端证据不能确认算法、提示词、数据质量或完成条件。
- **D：本项目设计判断**。从 BYOK 约束推导的推荐方案，不是原版内部实现事实。

静态存在不证明运行时一定执行，也不证明处理正确。协议形状、实际运行行为、真实质量结果是三个不同证据层。

## 3. 对原分析结论的收窄

| 原分析倾向 | 本次判断 | 对我们的影响 |
| --- | --- | --- |
| 服务端持有历史，A01 / A03 / A06 等在客户端被“消除” | 责任转移，不是质量证明；服务端也可能混淆建议、错误裁剪或检索失效 | 我们在本地明确承担这些责任，保留可追溯性 |
| 有槽位和纠错协议，问题调度已解 | 字段提供实现条件，未证明目标关联、并发取消和晚响应处理正确 | 使用问题 ID + 修订 + 尝试 ID + 写入校验，而不只复制字段名 |
| snapshot / onEnd 可以兜底截断，完成问题是 BYOK 独有 | 整段快照可以修复传输遗漏，不能补回模型因长度限制未生成的代码；双方都需终态判断 | 同时设计供应商终态和任务校验，不以收到 End 就判答案正确 |
| 预设和 assist 等于版本化提示管理 | 缓存时间、预设接口名不等于不可变版本、历史和可复现请求 | 明确模板 ID、版本、用户修订和请求清单 |
| 有声纹即可消灭说话人不确定 | 声纹有误接受、误拒绝和噪声条件；客户端也已有 uncertain 分支 | 默认保留不确定性，不为了对齐原版强制注册声纹 |
| 真实题库接口证明公司常考概率可靠 | 有统计服务不等于统计覆盖、样本代表性和时效已验证；真实通用题也不是用户亲历 | 没有自己的数据与采样说明时只给准备优先级建议 |
| 静默换模型证明已有持续评测闭环 | 换模型可由多种原因触发，没有评测记录不能证明质量验证 | 记录我们自己的基线、比较方法和结果，不借用厂商信誉 |
| customization 是结构化对象，所以用户自由文本不决定行为 | 该对象本身仍可包含自由文本与整段指令；内部优先级不可见 | 参数校验、稳定合同与自定义任务指令分开 |
| 新题请求不带简历，证明官方新题不用简历 RAG | 只能确认该次载荷未显式携带简历；服务端是否另取资料未知 | 我们仍默认不给独立算法题注入简历，但依据是任务需要与评测 |
| 把采集能力标志随 BYOK 请求上行 | 原版业务服务认识这些字段，通用模型未必认识 | 这些信息只用于本地规划，供应商适配器只发送受支持字段 |

原报告开头明确承认服务端不可见，这个限制应贯穿所有表格和汇总结论，而不只放在结尾。

## 4. 采纳、改造、暂缓与不采纳

| 原版模式或报告建议 | 决定 | 我们自己的方案 |
| --- | --- | --- |
| 答案槽位关联 | 借鉴目的，重新建模 | 一个问题多个修订、多个生成尝试，实答与建议分别关联；不依赖服务端分配 ID |
| correction / mergePrev | 借鉴交互 | 有明确目标、预期修订和撤回规则的本地命令；先支持人工，再评测自动合并 |
| 分阶段进度和快照 | 借鉴 | 内部统一进度事件、内容序号与可恢复快照；流式 token 不逐条长期落盘 |
| promptStudio | 分阶段采用 | 先注册和预览现有模板，再做风格 / 任务参数编辑，最后做有范围的专家自定义和可选 AI assist |
| 整段指令接管 | 不直接照搬 | 可以覆盖任务主体，但不能关闭来源、完成状态和数据权限合同；产品文案准确说明范围 |
| 岗位热词 | 改造后采用 | 简历 / JD 提取候选术语，用户检查后映射到已配置 ASR 支持的能力 |
| 声纹识别 | 暂缓 | 先区分采集来源、任务中的预期说话人和实际识别证据；声纹需要独立需求、数据处理方案和准确率评测 |
| 公司题频 / 押题 | 不伪造等价能力 | 无统计来源时用 AI 准备方向；若未来导入题库，另说明来源、样本期、统计口径 |
| 联网搜索 | 可选后续能力 | 真实搜索适配、授权、来源与时间戳，不以提示词要求模型“联网”冒充工具 |
| 服务端账号 / 额度 / 必需中转 | 当前不采用 | 维持本地 BYOK；用户配置供应商直连或其自己的兼容网关 |
| 无依据目标通过率 | 不采用 | 正确解答、暴力基线和学习错误案例分别标注，不保证伪造的通过率 |

“更好”的可检验方向是：事实不升级、纠错不串题、模型不完整时不假装完成、用户能知道资料怎么使用。不能据此声称整体质量已经超过原版，也没有必要复刻每一个原版按钮。
