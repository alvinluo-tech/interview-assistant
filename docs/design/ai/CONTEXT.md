# 面试助手 AI 领域词汇

本文只定义本设计范围内的业务词汇。数据字段与实现合同见 [架构方案](architecture.md)。

## 会话与题目

**会话（Session）**：一次连续的笔试、实时面试或模拟面试活动，具有明确的开始、结束和资料使用范围。
_避免_：将一个窗口、连接或模型请求称为会话。

**发言观察（Utterance Observation）**：采集或输入所得到的一次内容观察，可能不完整、说话人不明或识别有误。
_避免_：把每段转写都直接称为一道问题。

**问题（Question）**：当前需要处理的完整任务，可以由多条观察或多张截图构成。
_避免_：用一次截图、一条消息或一次生成请求替代问题身份。

**问题修订（Question Revision）**：同一道问题在纠错、补充约束后形成的一个明确版本。
_避免_：把重试称为修订，或覆盖原题而不保留变化关系。

**候选人实答（Candidate Response）**：候选人通过文字或已确认归属的语音实际表达的回答。
_避免_：将 AI 参考答案、转写身份猜测或系统回采等同于实答。

**参考建议（Answer Suggestion）**：AI 针对问题生成、候选人很可能采用或照读的答案。下一轮默认自然接续其中的技术方案、术语和约束，不逐轮询问是否采用；来源标记仍不等同于实际语音证据或个人项目事实。
_避免_：因内容被展示、复制或收藏，就称为个人事实；也避免因未显式确认而丢弃它、导致追问时突然更换技术方案。

**生成尝试（Generation Attempt）**：围绕一个确定问题修订进行的一次模型生成，重试产生新的尝试。
_避免_：将问题 ID 与请求 ID 或原版答案槽位混用。

## 资料与可信度

**资料快照（Knowledge Snapshot）**：会话选中资料及其版本的集合，描述本场允许使用的背景范围。
_避免_：将开场选出的若干片段称为完整知识快照。

**证据片段（Evidence Excerpt）**：可定位回某份资料版本或某条会话观察的内容。
_避免_：用检索相关性分数表示事实已获确认。

**内容来源（Origin）**：内容最初来自转写、手动输入、文件提取、模型生成或未知旧记录的事实。
_避免_：在用户确认内容后将原始来源改写为人工原创。

**事实确认（Assertion Confirmation）**：用户对某条明确陈述在相应范围内的确认，不代表整份资料或所有历史建议都正确。
_避免_：用一个全局 confirmed 标记认证整份 AI 答案。

**训练评价（Training Assessment）**：基于本场实答和训练条件产生的能力反馈。
_避免_：将未覆盖能力判为不会，或将训练分数称为录用概率。
