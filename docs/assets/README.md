# README 视觉素材

README 里用到的图片都放在这里。真实界面截图请务必先脱敏，再放进这个目录。

## 现有文件

| 文件 | 用途 |
| --- | --- |
| `brand.png` | 首页主视觉。由 `src/assets/brand.png` 缩放到 256×256，保留透明通道。 |

## 界面截图规格

`README.md` 与 `README.en.md` 里预置了一段注释掉的「界面预览」区块，截图准备好后取消注释即可显示。

| 项 | 要求 |
| --- | --- |
| 尺寸 | 1600×1000（2 倍图可 3200×2000 再压缩） |
| 格式 | PNG，单张控制在 400KB 以内 |
| 主题 | 深色优先，与品牌图配色一致；浅色可以各出一张 |
| 文件名 | `screenshot-interview.png`（面试浮窗）、`screenshot-exam.png`（笔试浮窗） |
| 内容 | 一张图只讲一件事：左边是输入（转写/题面），右边是浮窗输出 |

## 脱敏清单

截图前逐项确认：

- [ ] 简历、岗位、公司名换成占位内容
- [ ] 面试记录、历史列表里没有真实姓名与联系方式
- [ ] 题目与代码不含公司内部题目、内部域名、仓库地址
- [ ] 屏幕分辨率、用户名、桌面文件、任务栏图标不泄露本机信息
- [ ] 剪贴板预览、通知横幅已关闭
- [ ] 用纯色或虚化遮挡无法替换的区域

> 宁可用合成的示例数据重跑一遍再截图，也不要事后打码——打码过的图仍可能从字体边缘还原出原文。
