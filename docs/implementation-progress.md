- context 8 项通过，桌面验证 PDF worker、OCR 确认/取消、题库上下文及题库/收藏持久化。

## 第二阶段

- 百炼 Paraformer v2 原生 WebSocket、持续 PCM、临时字幕替换、定稿去重、热词 ID、超时、积压限制与重连；保留 MiMo 分段。

- 模拟窗口支持边录音边预览、结束后编辑、手动提交；录音时限和人声过滤，暂停自身 TTS，显示错误；修复带会话参数的路由。
- realtime 10 项、audio 26 项、BYOK 24 项通过，包含 600 句与反复断线的虚拟时钟回放。
- 真实 Rust 通道与实际模拟窗口 E2E 通过，使用本机合成服务/麦克风。尚无真实百炼 Key，识别准确率和网络延迟未验证。
